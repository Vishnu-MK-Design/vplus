## Dependencies and references

Dependency versions are pinned in `windows/package-lock.json`. Package licences remain in the installed dependencies; hls.js's licence is copied into generated player assets during preparation.

Public Netflix/WaveStream-style discovery patterns and React Bits' rounded/tabbed interaction references informed the design direction. V+ is independently directed and implemented and is not an official client of those services. A playback provider's embed documentation does not establish redistribution rights for the underlying films or episodes.
